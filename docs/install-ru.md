# CoinsPay для XenForo: установка

Дополнение позволяет участникам оплачивать платные группы (user upgrades) криптовалютой на странице оплаты CoinsPay. Работает на XenForo 2.2 и 2.3. Нужен аккаунт [CoinsPay](https://coinspay.app) с магазином.

Названия разделов панели администратора даны по-английски, как в XenForo без пакета перевода. Поля дополнения подписаны на языке вашей панели — по-русски или по-английски; английские названия даны в скобках.

## 1. Установите дополнение

1. В панели администратора откройте Add-ons, нажмите «Install/upgrade from archive» и выберите `coinspay-xenforo-<версия>.zip`.

   Эту кнопку XenForo показывает, только если в `src/config.php` есть строка `$config['enableAddOnArchiveInstaller'] = true;`. Без неё скопируйте содержимое папки `upload/` из архива в корень форума, туда, где лежит `index.php`, затем найдите «CoinsPay: crypto payments» на странице Add-ons и нажмите Install.

## 2. Создайте платёжный профиль

1. Setup → Payment profiles → Add payment profile, выберите CoinsPay и нажмите Proceed. Отображаемое название видят участники, например «Криптовалюта (USDT, USDC, BTC и другие)».
2. В кабинете CoinsPay откройте свой магазин:
   - в разделе «Ключи API» создайте ключ с доступом «Только счета». Для первой оплаты отметьте «Тестовый ключ»: он начинается с `cpk_test_`. Вставьте его в поле «Ключ API» (API key);
   - в разделе «Вебхук» впишите «Адрес вебхука» (Webhook address), который показывает форма, сохраните и скопируйте секрет `whsec_…` в поле «Секрет вебхука» (Webhook secret).
3. Сохраните профиль. Панель вверху формы должна показать ваш магазин CoinsPay. Нажмите «Отправить тестовое событие» в кабинете CoinsPay и обновите форму: панель покажет, когда пришло событие.

## 3. Подключите профиль к платной группе

Users → User upgrades: откройте платную группу без автопродления (на срок или навсегда) и отметьте профиль CoinsPay в поле «Payment profile». Оплата криптовалютой не продлевается сама, поэтому XenForo не даёт подключить профиль к группе с автопродлением. Цена должна быть в валюте, которую принимает CoinsPay.

## 4. Первая оплата — тестовая

1. Войдите администратором, откройте на форуме Account upgrades и купите эту группу через CoinsPay. Тестовым ключом могут платить только администраторы.
2. На странице оплаты CoinsPay с пометкой «Тестовый счёт» выберите монету и нажмите «Оплатить».
3. В течение минуты группа должна появиться у вашего аккаунта, а в Logs → Payment provider log — строка «Payment received» со счётом CoinsPay.
4. Завершите тестовую группу в Users → User upgrades → Active upgrades и замените тестовый ключ на боевой (без отметки «Тестовый ключ»).

Если группа не появилась, пришлите строки журнала платёжных систем и то, что показывает панель профиля, в [поддержку CoinsPay](https://t.me/coinspayapp) или на support@coinspay.app.

## Удаление

Удалите дополнение на странице Add-ons (Uninstall). Вместе с ним удаляются платёжный провайдер, его задача cron и маршрут, таблицы `xf_coinspay_invoice` и `xf_coinspay_kv`. Удаляйте, только когда ни один счёт CoinsPay не ждёт оплаты: платёж по счёту, созданному раньше, уже не применится.
